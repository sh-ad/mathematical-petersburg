# Математический Петербург · из уст в уста

Два отдельных статических сайта для экскурсии о передаче идей и возникновении научной школы.

- Участникам: https://sh-ad.github.io/mathematical-petersburg/participants/
- Ведущему: https://sh-ad.github.io/mathematical-petersburg/presenter/
- Подробный справочник: https://sh-ad.github.io/mathematical-petersburg/reference/
- Источники: https://sh-ad.github.io/mathematical-petersburg/sources/

## Участникам

16 крупных экранов с пятью портретами, историческим видом университета, схемами передачи идей, датами, задачей о мостах, анимацией механизма Чебышёва, управляемым прогнозом Маркова, подсчётом переходов букв в отрывке «Онегина», школьной схемой равновесия, графиком производной и упражнением о волчке.

Навигация кнопками, стрелками клавиатуры, Home/End или через «Все экраны». У ползунков и элементов задачи клавиши сохраняют обычное действие. Ответы раскрываются отдельно. Анимация включается пользователем и останавливается при уходе с экрана. У каждого экрана — постоянный адрес по якорю.

## Ведущему

16 карточек: место и рабочий бюджет времени, цель, вопрос группе, действие, опорный ответ, переход, раскрываемая реплика ведущего, точность формулировок и источники. Ссылки открывают нужный экран участников в отдельной вкладке. Кнопка печати создаёт компактный вариант с вопросами, действиями и ответами.

Компактная композиция — три места сбора: Кунсткамера/Академия → Двенадцать коллегий → Дом академиков. Шесть исторических адресов сохранены в справочнике; переход к дому Эйлера и на 6-ю линию необязателен. Натурный обход, расстояния и слышимость не проверены; 75–90 минут — целевой формат, а не измеренное время.

## Локально и без интернета

Скачать `docs/downloads/offline.zip`, распаковать и открыть `participants/index.html` или `presenter/index.html`. Изображения, схемы, JS и стили локальные; сервер не нужен. Внешние исторические источники требуют интернета. В архиве нет ограничений доступа: это тот же общедоступный учебный материал.

## Сборка и проверка

Нужны Python 3 и Node.js 20+ для тестов. Зависимостей для установки нет.

```sh
python3 src/build.py
node --test tests/model.test.js
node qa/check-browser.js
```

Браузерная проверка использует установленный Google Chrome; путь можно задать переменной `CHROME_BIN`. Она запускает отдельный временный профиль и не использует личные вкладки или данные браузера.

GitHub Pages публикует ветку `main`, каталог `/docs`. Сборка статических страниц не требует GitHub Actions; в `docs` есть `.nojekyll`.

## Источники и авторство

Первичные свидетельства и ограничения подписаны в интерфейсе. Короткие русские цитаты Эйлера и Фусса — переводы фрагментов английской передачи MacTutor; оригинальные автографы не сверялись. Поздние воспоминания Ковалевской отделены от современных реплик ведущего. Исходные исследовательские материалы лежат в `materials/`.

Пять исторических портретов и исторический вид университета — public domain по карточкам хранилища. Анимация: Van helsing, 2007, CC BY 2.5; исходный GIF не изменён, отдельный PNG — первый кадр для остановленного состояния. Полная атрибуция — `materials/image-sources.md` и сайт источников. Остальные схемы созданы для этого учебного материала и не изображают архивные документы или точные исторические приборы.

Марковские вероятности трафика и серии времени до падения вымышлены. Схема мостов оптимизирует число пересечений, а не километры. Школьные виды равновесия — вход в более общую теорию; обычный волчок не реализует специальный случай Ковалевской. Подробный справочник сохраняет тексты прежней редакции 1.1 с отдельным предупреждением об отличиях маршрута.
